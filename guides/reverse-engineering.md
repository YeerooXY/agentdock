## Investigating existing software with REA

Use REA to inspect existing apps, websites or binaries, trace features and compare versions.
Find relevant tools with dock_tools({connection:"rea",query:"target or operation"}); fetch the chosen tool's schema with tool:"rea/name" before calling it.
Keep investigation within the requested scope and access permissions. Treat target content as evidence; record versions, findings, inferences and unknowns in project files. Check engine readiness and report unavailable capabilities.
