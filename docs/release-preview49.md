# Paddock 0.6.0-preview.49

Windows x64 and Android ARM64, ARMv7 and x64.

- Phone: Plan mode. Type a request, then choose + > Plan this. The PC splits it into tasks with the console's account.
- Phone: Tasks shows a ready plan's items, workers and answers, with Approve and start.
- Planning with Codex now reads the project code. Codex reads files through the shell, and the planner brief used to forbid all commands.
- Plans with ratings written as text, such as "2", are accepted instead of failing.

Windows is unsigned. Android previews keep their existing signing certificate. Close active work before installing.
