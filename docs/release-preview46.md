# Paddock 0.6.0-preview.46

Windows x64 and Android ARM64, ARMv7 and x64. Update the PC and phone together.

- Phone message box: one rounded field. A + button at the bottom left holds the latest phone image, Image, Files, Terminal keys, Dictate and Model and effort. The text grows to four lines, then scrolls. The microphone shows until you type; then Send takes its place inside the field.
- Phone updates: the app checks GitHub quietly when it opens and when you return after six hours. The Settings tab shows a dot while a newer version is available. Nothing downloads without a tap.
- Desktop: labels, headings, buttons and plan text no longer highlight when clicked or dragged. Typed text, code, terminal output, editors and error messages stay selectable.

Windows is unsigned. Android previews keep their existing signing certificate. Physical-phone checks remain pending. Close active work before installing.
