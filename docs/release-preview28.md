# Paddock 0.6.0-preview.28

Windows desktop update. Android preview 27 remains available; this release does not require a new phone installation or pairing.

- Task routing prefers a ready local worker, then eligible free and included accounts with remaining allowance. Named Codex accounts retain their selected model routes. Smaller suitable models handle routine work; Astra requires explicit escalation.
- Shared startup instructions expose routing and creative constraints. New bounded worker adapters support Cline, Gemini, Kimi, Droid and Pi where the native account is eligible. Cursor and Qwen remain coordinators while incoming-worker restrictions are unverified.
- Usage includes Antigravity, Cursor, Copilot and Pi readers, limiting-window exhaustion, restored hidden subscriptions, and corrected native cached-token accounting. Unknown quotas remain unknown. Pi's OpenRouter reader distinguishes free models from paid models on a free account.
- Console recovery and MCP connection handling are improved for Antigravity, Grok, Cline and Kiro. Provider authentication and plan requirements still apply.
- Projects, Tasks, Results and Usage use the revised navigation and layouts. The desktop file explorer, Code panels and embedded website Preview panels are removed. Console file-link previews remain available.
- Study sessions receive focused context and timer handling. Upscayl can be installed and connected as an optional local Windows image tool.

The installer preserves the existing local profile. Close active work before installing. This preview is unsigned.

## Verification and limits

The source passed Windows and Linux unit suites and the headless desktop suites. Release checks cover the bundled runtime, application assets, isolated startup, a real terminal, MCP connection and restart/restore. Automated tests use fixtures and make no paid model requests.

Nine native CLI coordinators called the shared tools during the routing audit. This does not establish every possible live provider-to-provider combination. Pi's new incoming SDK runner still needs a completion after quota reset; Gemini, Kimi and Droid need eligible accounts. Cline interactive mode remains separately unverified.

The website pilot reused local drafts and a free-account review, but coordinator overhead prevented a demonstrated cost saving. No general cost or speed improvement is claimed.
