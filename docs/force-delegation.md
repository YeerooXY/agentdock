# Task-fit delegation

The opt-in skill keeps its existing `force-delegation` ID so saved selections remain valid. Its policy now permits direct lead work when delegation adds overhead or suitable workers are unavailable.

Choose capability and context capacity for the actual task, then compare funding among suitable accounts. Large cross-module reviews need an explicitly selected model with sufficient context and demonstrated ability. Model-name tiers remain hints. Free or local availability alone establishes no task suitability.

Strata readiness checks `/models` and expires after 60 seconds. It describes endpoint/model availability and performs no inference benchmark. Automatic local suggestions apply only to explicitly small tasks. Medium work, large work and reviews start at the higher routing tier; the selector leaves tasks unassigned when only weaker discovered models are available. Existing explicit owner assignments remain intact.

Workers keep bounded briefs, file ownership and applicable enabled skills. A failed attempt stops. The lead can continue within existing authorization after the worker releases its files. Spending limits, account-wide quota checks and explicit owner choices remain in force.

Skill delivery uses the existing managed manifests and hash checks. Modified user copies are preserved. Savings require equivalent accepted work and complete usage accounting.
