# Paddock 0.6.0-preview.50

Windows x64 and Android ARM64, ARMv7 and x64.

- Phone: choose up to ten photos at once with + > Image. Each photo uploads in turn and adds its own line to the message.
- Phone: after you attach a photo, the message box scrolls to the new line instead of staying at the top.
- Interface reviews check reduced motion per element: every animation needs a reduced-motion override that matches it, and endless animations are reported. The browser review also compares running animations with reduced motion on and off.
- Interface guidance asks agents to specify motion, focus and screen-reader announcements for each state change, and to keep a per-project record of which screens have been reviewed.

Windows is unsigned. Android previews keep their existing signing certificate. Close active work before installing.
